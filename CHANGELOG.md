## 0.1.0 - 2026-09-05

### Added

- Published the 57-skill SECOD catalog.
- Added installation support through the Skills CLI.
- Added installation instructions for Codex, Claude Code and Cursor; full
  installation verification remains a release gate.

### Security

- Added repository validation and hygiene checks.
- Added private vulnerability reporting guidance.
- Added documented secret-scanning and protected-branch release requirements.

### Known limitations

- Not every skill has an executable fixture.
- Some provider controls remain provisional or pending evidence review.
- SECOD is guidance and verification assistance, not a security certification.
